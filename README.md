# CULTURE THRIFTS

Culture Thrifts is a modern streetwear and thrift-inspired ecommerce website UI built using React, Vite, Tailwind CSS, and Lucide React icons.

The project includes:

- Shopping cart sidebar
- Navbar with search
- Product cards
- Categories section
- Hero section
- Footer
- Modern responsive layout

---

# HOW TO RUN

## Install dependencies

```bash
npm install
```

## Install Lucide React

```bash
npm install lucide-react
```

## Start development server

```bash
npm run dev
```

Open the local server shown in the terminal:

```bash
http://localhost:5173
```
